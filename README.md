# Need4Data-Blue-Bumper-Cars

Need4Data: 2026 Datathon
This repository holds the code our team used to clean, visualize, and model the data from the "US Accidents (2016-2023)" Kaggle Dataset.

Dependencies:
- "US Accidents (2016-2023)" Kaggle Dataset
- Python
- Jupyter Notebook or Google Colab
- NumPy
- pandas
- matplotlib.pyplot
- seaborn
- os
- missingno

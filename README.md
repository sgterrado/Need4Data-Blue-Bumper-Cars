# Need4Data-Blue-Bumper-Cars

This repository holds the code our team used to clean, visualize, and model the a sample of 500,000 data from the "US Accidents (2016-2023)" Kaggle Dataset.

Dependencies:
- "US Accidents (2016-2023)" Kaggle Dataset
- Python
- Jupyter Notebook or Google Colab
- NumPy
- pandas
- matplotlib.pyplot
- seaborn
- os
- missingno
- tensorflow
- sklearn
- xgboost
